## Project Overview
Khanyisani's Skin Care is a proudly South African skincare e-commerce website based in Pretoria. The brand name "Khanyisani" means "to bring light" - promising to restore confidence and glow for all skin types.

The website showcases affordable, results-driven skincare products formulated for South African weather, water, and skin tones. It targets common concerns: pimples, dry flaky skin, dark spots, and dullness.

The site is built with HTML5 and external CSS (`css_assets/myfirststyles.css`) and is responsive for mobile devices.

## Website Goals and Objectives
1.  **Build Brand Awareness:** Introduce Khanyisani's Skin Care story and values.
2.  **Product Showcase:** Display 5 core products and 3 bundle kits with pricing.
3.  **Customer Education:** Explain ingredients and how to use products correctly.
4.  **Lead Generation:** Allow customers to enquire via Enquiry form and contact via WhatsApp/Email.
5.  **Accessibility:** Simple navigation, clear pricing in Rands, and mobile-friendly layout.
6.  **Future Goal:** Enable online ordering and nationwide courier delivery.

## Key Features and Functionality
- **Responsive Header:** Logo (180px) + Navigation bar (Homepage, Services, Contact, About, Pricing, Enquiry) with `aria-label="main navigation"`.
- **Homepage:** Brand intro and hero image.
- **Services Page:** "Our Skincare Experience" with 7 product lifestyle images (350x350px).
- **Pricing Page:** 3 Bundle deals (Glow Starter Kit R550, Clear Skin Kit R580, Full Glow Bundle R950) and 5 single products (R200-R250) with gold colour #D4AF37.
- **About Page:** Our Story, Ingredients (Water, Glycerin, Natural Oils, Actives), How To Use (use-box divs), Values and How To Shop.
- **Contact Page:** Contact table with Phone, WhatsApp link, Email, Address (Pretoria + Centurion Mall Shop 15), Hours.
- **Enquiry Page:** Form with Name, Surname, Email, Phone Number, Enquiry Type (Combo/Standalone dropdown), Message textarea, Submit button.
- **Styling:** Background #FFF8F0 for header, gold pricing highlights, external stylesheet.
